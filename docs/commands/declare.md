# DECLARE

Declares the new variable within the current execution scope. Variables are case-insensitive. If a variable with the same name has already been declared within the current scope, an error occurs.

## Syntax

```
DECLARE var_name [ := value ]
```

## Examples

```
DECLARE vk_password; -- Null variable.
DECLARE token := 'go4kysokm6340jGsd';
```
